# 00 SSOT - CS7-SC Website Kelas

- Tujuan: website kelas, fokus frontend dulu, tanpa backend.
- Stack: Astro 7 (SSG), TypeScript strict, CSS murni (tanpa framework dulu).
- Bahasa: Indonesia.
- Workflow wajib sebelum backend: Lint, Unit Test, Dependency Check, Build via GitHub Actions.
- SSOT menang: file ini + `01_CONTEXT.md` + `02_RULES.md`. Kalau konflik, SSOT menang.
- No scope creep: jangan tambah backend/auth/database sebelum disetujui.
- Numbers Lock: jangan pajang angka/testimoni tanpa sumber nyata.
